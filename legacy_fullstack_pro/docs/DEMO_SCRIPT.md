# 5-Minute SIH Demo

1. Open RunProof dashboard already logged in.
2. Upload `demo/broken_project` as a ZIP.
3. Run Check.
4. Show RunProof Doctor:
   - missing environment settings,
   - unpinned dependencies.
5. Explain why the readiness score is below 100.
6. Upload/fix the good project.
7. In trusted local demo mode, click Verify.
8. Show Clean Build A and Clean Build B.
9. Show matching SHA-256 artifact fingerprints.
10. Open the signed RunProof Passport.
11. Download the evidence bundle.
12. Finish with: **“Don’t say it runs. Prove it runs again.”**
