# RunProof Product Vision

RunProof should not feel like many unrelated pages.

Every screen must answer five things visually:

1. What am I doing now?
2. What is RunProof doing in the background?
3. What happened?
4. Why did it happen?
5. What should I do next?

## Product journey

Account → Secure OTP → Dashboard → Project → Scan → Understand → Check → Doctor → Score → Verify → Passport → Report

## Four product pillars

### Inspect
Understand the project.

### Doctor
Explain problems and fixes.

### Verify
Create reproducibility evidence.

### Passport
Create proof that can be shared.

## UI rule

Do not add features only as text.

Every important feature should have:
- clear icon
- strong heading
- one-line purpose
- visual state
- example output
- next action
